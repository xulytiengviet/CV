# Long Ngo — Academic & GeoAI Portfolio

This repository hosts the source overlay for Long Ngo's academic, GIS/GeoAI, and open-source portfolio.

The site is built as a lightweight downstream of [al-folio](https://github.com/alshedivat/al-folio), pinned to a known release and deployed with GitHub Actions to GitHub Pages.

> Development happens through pull requests. The production site is built from the `main` branch.
