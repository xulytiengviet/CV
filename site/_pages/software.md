# Open-source work

GitHub is used as the engineering and reproducibility layer behind this research portfolio.

## Active repositories

### [BilaScript](https://github.com/xulytiengviet/bilascript)
Programming-language and educational tooling experiments, including browser exercises, AST-oriented processing and JavaScript execution paths.

### [BILATiny](https://github.com/xulytiengviet/bilatiny)
Compact AI/model research for constrained devices and edge-oriented applications.

### [Basemap](https://github.com/xulytiengviet/basemap)
Open geospatial basemap work, including PMTiles-oriented distribution and reusable WebGIS delivery patterns.

### [Carbon](https://github.com/xulytiengviet/carbon)
GIS and educational tooling related to carbon monitoring, forest-carbon services and environmental analysis.

### [Vinh Long](https://github.com/xulytiengviet/vinhlong)
Public-facing web and geospatial experiments focused on Vinh Long and the wider regional context.

### [GIS2026](https://github.com/xulytiengviet/gis2026)
Repository-centered organization and publication workflow for GIS2026 materials.

## Engineering principles

Projects in this portfolio aim to be open and inspectable, browser-first where practical, offline-capable when field use requires it, standards-oriented, AI-ready through explicit tool contracts, and reproducible through Git history, releases and automated builds.
